# Gemini API モデル選定ポリシー

## 適用ルール
Gemini API を使用するコード生成や設計を行う際は、以下の基準を厳格に遵守すること。

1. **最新版を最優先で選定する**:
   - 現行の最新バージョン（`gemini-3.8-flash`、次点で `gemini-3.7-flash`, `gemini-3.6-flash`）を標準採用する。
   - 古いモデル（2.5系や1.5系など、すでに提供終了または廃止されたモデル）は絶対に指定しない。
2. **将来のバージョンアップ時**:
   - 4.0系がリリースされた場合は 4.0系を第一候補とし、その直前世代（3.8など）をフォールバックとする。
3. **常に最新または直近1〜2世代以内のモデルのみを使用する**。
