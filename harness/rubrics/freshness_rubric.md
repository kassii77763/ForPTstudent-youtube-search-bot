# 評価基準表 (Rubric): 情報鮮度・時間軸整合性 (Freshness & Temporal Grounding)

## 1. 評価概要
エージェントが出力する技術仕様、モデル名、バージョン、API仕様、利用料金が、**現在システム時刻（2026年）における最新の公式事実と適合しているか**を客観判定するModel Grader用ルーブリック。

## 2. 採点基準 (Rubric 1 - 5)

| スコア | 判定 | 定義・評価基準 | 判定アクション |
| :---: | :---: | :--- | :--- |
| **1** | **致命的欠陥 (Critical)** | 2〜3年以上前の廃止または旧世代モデル（例: Gemini 1.5 Flash）を、現行の最新事実であるかのように断定して回答している。 | **即時FAIL（自律リトライ）** |
| **2** | **不十分 (Poor)** | 一部最新情報に触れているが、古いデータや過去の料金体系が混在しており、ユーザーに誤解や誤認を与える。 | **要修正（警告）** |
| **3** | **許容 (Acceptable)** | 古い情報であることを明記した上で「歴史的経緯や過去事例」として言及しており、現行最新との区別が論理的になされている。 | 条件付きPASS |
| **4** | **良好 (Good)** | 現在（2026年）の最新モデル・公式仕様をベースに議論が展開され、事実関係に誤りがない。 | **PASS** |
| **5** | **模範 (Exceptional)** | 最新モデルの仕様・制約・料金を一次情報に即して正確に提示し、将来の変動リスクや注意点まで客観的・多面的に言及している。 | **PASS (EXCELLENT)** |

## 3. 審査員AI（Evaluator LLM）の思考ステップ
1. **事実抽出**: 出力文から「年号」「AIモデル名」「バージョン番号」「API料金」「機能名」を抽出する。
2. **時間軸照合**: 現在年（2026年）と照合し、言及された技術が旧世代でないかを確認する。
3. **断定度判定**: 旧世代情報を「現在の仕様」として断定している場合、無条件でスコア1〜2とする。
4. **スコアリング**: スコアと減点理由（1行）を出力する。
