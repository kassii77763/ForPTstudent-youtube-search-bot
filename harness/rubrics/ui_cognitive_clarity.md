# 評価基準表 (Rubric): システム回路図・トポロジー視認性 (Cognitive Clarity Rubric)

## 1. 評価概要
エージェントが生成するアーキテクチャ図、ダッシュボード、配線トポロジーが、**一目で因果関係・循環ループ・例外処理を認知できる構造になっているか**を判定するルーブリック。

## 2. 採点基準 (Rubric 1 - 5)

| スコア | 判定 | 定義・評価基準 | 判定アクション |
| :---: | :---: | :--- | :--- |
| **1** | **致命的欠陥 (Critical)** | 単なる横並びの静的カード列やテキスト箇条書きに留まり、データの流れやノード間の因果関係が視覚的に表現されていない。 | **即時FAIL（再設計）** |
| **2** | **不十分 (Poor)** | 矢印などの記号はあるが、上下左右の接続関係が断絶しており、どこからどこへ制御が渡るのか追うのに認知的負荷がかかる。 | **要修正** |
| **3** | **許容 (Acceptable)** | 入力から出力への主幹線（ハッピーパス）は追えるが、例外処理、承認ゲート、フィードバック再帰ループが省略されている。 | 条件付きPASS |
| **4** | **良好 (Good)** | ベクター配線と矢印により、入力・ガード・AI・出力・再帰ループのトポロジーが整理され、迷わず追える。 | **PASS** |
| **5** | **模範 (Exceptional)** | 全体サイクル（局所とメタ）の循環関係が一目で直感でき、各ノードをクリックして詳細仕様をインスペクトできる高度な認知体験を提供する。 | **PASS (EXCELLENT)** |

## 3. 審査員AI（Evaluator LLM）の思考ステップ
1. **配線追跡**: 入力ノードから最終出力ノードまで、有向グラフとして線がつながっているか確認する。
2. **閉ループ検査**: 失敗回収から次期ガードレールへのフィードバック（再帰線）が存在するか確認する。
3. **インタラクティブ性検査**: 画面上の要素が静止画に留まらず、詳細情報を展開可能か判定する。
