# 解剖学講義資料②：神経系の発生・脳室系・髄膜・脳脊髄液と循環
小テスト対策まとめ（2026年10月22日実施対応）

---

## 第1章：神経系の発生と胚葉分化

### 1. 胚子の初期発生
- **受精2週齢**: 2層性胚盤（将来の胎児となる部分）。
- **受精3週齢**: **3胚葉**に分化（**外胚葉、中胚葉、内胚葉**）。
- **外胚葉 (Ectoderm) の運命**: 将来の**神経系（中枢神経・末梢神経）**および**表皮**になる。

### 2. 中枢神経系の原基形成
- 外胚葉が肥厚して**神経板**を形成 → 陥凹して**神経溝**・**神経ヒダ**を形成 → 癒合して管状の**神経管**となる。
- **神経管 (Neural tube)**: **中枢神経系（脳・脊髄）**の原基となる。
  - 神経管の内腔が将来の**脳室系・脊髄中心管**となる。
  - 神経管の頭頂端を**終板**と呼ぶ。
- **神経堤 / 神経提 (Neural crest)**: 神経管閉鎖時に背外側に遊離する細胞群。**末梢神経系**（脳神経節、脊髄後根神経節、自律神経節、シュワン細胞など）の原基となる。

### 3. 脳胞の分化（発生過程）
- **第4週（3脳胞期）**:
  1. **前脳胞** (Forebrain)
  2. **中脳胞** (Midbrain)
  3. **菱脳胞** (Hindbrain)
- **第5週以降（5脳胞期）**:
  - 前脳胞 → **終脳**（大脳半球、側脳室） ＋ **間脳**（視床・視床下部、第三脳室）
  - 中脳胞 → **中脳**（中脳水道）
  - 菱脳胞 → **後脳**（橋・小脳） ＋ **髄脳**（延髄、第四脳室）
- 脊髄の内腔は**中心管**となり、胎生期の形態を最も色濃く残す。

## 第2章：中枢神経の先天異常（神経管閉鎖不全）

神経管（神経ヒダ）の閉鎖異常によって生じる先天異常。周囲の脊椎、頭蓋骨、皮膚、筋肉の形成不全を伴う。
- **発症予防**: **妊娠前〜妊娠1〜3か月までの葉酸（ビタミンB9）摂取**により発症リスクが有意に低下する。

### 1. 頭部の閉鎖不全
- **無脳症 (Anencephaly)**: 神経管頭側の閉鎖不全。大脳・頭蓋骨が形成されない（重度、生命予後不良、外科的治療困難）。
- **脳瘤 (Encephalocele)**: 頭蓋骨欠損部から脳組織や髄膜が脱出する（中等度、外科的修復可能）。

### 2. 尾部の閉鎖不全：二分脊椎 (Spina Bifida)
脊椎の椎弓が正常に閉鎖せず二股に離開する病態。
1. **潜在性二分脊椎（軽度）**:
   - 神経組織の脱出はなく、皮膚に覆われる。
   - 体表所見として局所の**異常発毛**、皮膚陥凹、色素沈着が見られる。症状や麻痺は現れないことが多い。
2. **髄膜瘤（中等度）**:
   - 髄膜と髄液のみが皮下に嚢胞状に脱出。神経組織は含まない。
3. **脊髄髄膜瘤（重度）**:
   - 脊髄や神経根が嚢胞内に脱出。露出しているため**48時間以内の緊急閉鎖手術**が必要（中枢神経感染予防）。
   - **症状**: 進行性の下肢弛緩性麻痺、感覚障害、膀胱直腸障害。
   - **代表的合併症**:
     - **Chiari（キアリ）奇形II型**: 延髄や小脳虫部が大後頭孔から脊柱管内へ下垂する。
     - **水頭症**: 中脳水道の圧迫・狭窄による髄液循環障害。
     - **内反足**: 下肢筋力不均衡による骨関節変形。

## 第3章：脳室系と連絡路

脳室系は神経管の内腔に由来し、すべて**脳脊髄液 (CSF)** で満たされている。

### 1. 各脳室の名称と位置
- **側脳室 (Lateral ventricle)**: 左右の大脳半球（終脳）内に1対存在。
  - 前角（前頭葉内）
  - 体部（頭頂葉内）
  - 後角（後頭葉内）
  - 下角（側頭葉内）
  - **透明中隔**: 左右の側脳室前角を隔てる薄い膜。
  - 側脳室を取り囲む構造：尾状核、海馬、脳梁、視床、脳弓。
- **第三脳室 (Third ventricle)**: 間脳の正中にある左右に狭いスリット状の空間。左右の**視床および視床下部**に挟まれる。
- **中脳水道 (Cerebral aqueduct / シルビウス水道)**: **中脳**を貫通する細い管。第三脳室と第四脳室を連絡する。
- **第四脳室 (Fourth ventricle)**: 前方を**橋・延髄**背側（菱形窩）、後方を**小脳**に囲まれたテント状の空間。
- **中心管 (Central canal)**: 脊髄の全長を貫く細管。第四脳室下端から連続する。

### 2. 脳室の連絡孔と出口（超重要）
- **室間孔（モンロー孔 / Foramen of Monro）**: **側脳室**と**第三脳室**を連絡する。
- **中脳水道**: **第三脳室**と**第四脳室**を連絡する。
- **外側口（ルシュカ孔 / Foramen of Luschka）**: 第四脳室外側部にある左右1対（計2個）の出口。第四脳室から**クモ膜下腔**へCSFを流出させる。
- **正中口（マジャンディー孔 / Foramen of Magendie）**: 第四脳室後下端正中にある1個の出口。第四脳室から**クモ膜下腔**（大槽）へCSFを流出させる。

## 第4章：水頭症 (Hydrocephalus)

### 1. 病態と原因
脳室系内の髄液過剰産生、循環路閉塞、または吸収障害により、脳室内にCSFが過剰に貯留し脳室が拡大する病態。
- **先天性・新生児水頭症の原因**:
  - 先天性中脳水道狭窄症
  - X連鎖性遺伝性水頭症
  - 胎内垂直感染（トキソプラズマ等）
  - **脊髄髄膜瘤 ＋ Chiari奇形II型**（高頻度で合併）
  - **Dandy-Walker症候群**: 小脳虫部の形成不全、第四脳室が嚢胞状に拡大。
  - 頭蓋縫合早期癒合症

### 2. 治療法
- **短絡手術（シャント術）**: 余剰のCSFを腹腔や心房へ逃すカテーテルを留置する。
  - **V-Pシャント（脳室-腹腔シャント）**: 最も一般的。側脳室から皮下を通して腹腔内に流す。
  - **V-Aシャント（脳室-心房シャント）**: 側脳室から右心房へ流す。

## 第5章：髄膜の解剖（3層構造と空間）

脳と脊髄は外側から順に **硬膜 → クモ膜 → 軟膜** の3層の髄膜に包まれている。

### 1. 髄膜と空間の区分
1. **硬膜 (Dura mater)**: 最外層の強靭な結合組織膜。
   - **脳硬膜**: **2層（外葉と内葉）**で構成される。外葉は頭蓋骨内面の骨膜に密着。外葉と内葉が離開する部位に**硬膜静脈洞**が形成される。
   - **脊髄硬膜**: **1層**のみ。椎骨の内面骨膜とは癒着せず離れている。
2. **硬膜外腔 (Epidural space)**:
   - 頭蓋内：通常は存在しない（骨膜と外葉が癒着）。外傷時に剥がれて血腫ができる。
   - 脊柱管内：硬膜と椎骨骨膜の間に広い脂肪組織・静脈叢の空間が存在 → **硬膜外麻酔**に利用される。
3. **硬膜下腔 (Subdural space)**: 硬膜とクモ膜の間の潜在的間隙。
4. **クモ膜 (Arachnoid mater)**: クモの巣状の線維小柱（クモ膜小柱）を軟膜へ伸ばす薄膜。
5. **クモ膜下腔 (Subarachnoid space)**: クモ膜と軟膜の間の空間。**脳脊髄液 (CSF)** で満たされ、脳表を走る主要な太い**動脈・静脈**が走行する。
6. **軟膜 (Pia mater)**: 最内層。脳・脊髄の実質表面に強固に癒着しており、**脳から剥離できない**。脳実質に入る細血管の周囲にも連なり、**血管周囲腔（Virchow-Robin腔）**を形成する。

### 2. 頭蓋内出血の病態・画像特徴（重要）
| 出血の種類 | 損傷血管・好発部位 | CT画像所見の特徴 | 臨床的特徴 |
| :--- | :--- | :--- | :--- |
| **硬膜外出血（血腫）** | **中硬膜動脈**（側頭骨骨折、棘孔通過） | **凸レンズ型（両凸型）** | 骨縫合線を越えない。一時的な意識清明期（lucid interval）あり。 |
| **硬膜下出血（血腫）** | **架橋静脈**（脳表と静脈洞を結ぶ静脈） | **三日月型** | 骨縫合線を越えて広がる。高齢者の脳萎縮・軽微な外傷で慢性硬膜下血腫を生じやすい。 |
| **クモ膜下出血 (SAH)** | **脳動脈瘤破裂**（ウィリス動脈輪）、脳動静脈奇形 | **脳槽・脳溝に沿った高吸収域（星型/ヒトデ型）** | 突発する「バットで殴られたような」激しい頭痛。髄液は血性・キサントクロミー陽性。 |

## 第6章：硬膜の隔膜と静脈洞

### 1. 硬膜が形成する隔膜
- **大脳鎌 (Falx cerebri)**: **大脳縦裂**に入り込み、左右の大脳半球を隔てる鎌状の硬膜ヒダ。
- **小脳テント (Tentorium cerebelli)**: **大脳横裂**に入り込み、大脳（後頭葉）下面と小脳上面を隔てる水平方向の硬膜ヒダ。

### 2. 硬膜静脈洞の走行と還流
脳の静脈血および吸収されたCSFが流れ込む。弁を持たない。
- **上矢状静脈洞**: 大脳鎌の上縁を走行。クモ膜顆粒が突出し、CSFが排泄される。
- **下矢状静脈洞**: 大脳鎌の下遊離縁を走行。
- **直静脈洞**: 大脳鎌と小脳テントの接合部を走行。下矢状静脈洞と**大大脳静脈（ガレン静脈）**が合流する。
- **静脈洞交会**: 上矢状静脈洞、直静脈洞、後頭静脈洞が合流する部位。
- **横静脈洞**: 後頭骨内面の横溝、小脳テント外縁を走行。
- **S状静脈洞**: 横静脈洞から連続してS字状に湾曲。
- **頚静脈孔**: S状静脈洞がここを通過して**内頚静脈**となり、腕頭静脈 → 上大静脈を経て心臓（右心房）へ還流する。

### 3. 海綿静脈洞 (Cavernous sinus)
トルコ鞍・蝶形骨体の両外側にある網目状の静脈洞。
- **貫通・側壁を通る重要構造**:
  - 動眼神経 (CN III)
  - 滑車神経 (CN IV)
  - 外転神経 (CN VI)
  - 三叉神経第1枝（眼神経 V1）
  - 三叉神経第2枝（上顎神経 V2）
  - **内頚動脈**
  - 下垂体に隣接
- **臨床的重要性**: 顔面静脈・上眼静脈と交通しているため、**顔面の化膿性炎症（鼻・口唇周囲のニキビ・感染症）が逆行性に海綿静脈洞血栓症を引き起こすリスク**がある。

## 第7章：クモ膜顆粒、くも膜下槽、脳脊髄液の循環動態

### 1. クモ膜下槽（脳槽）
クモ膜下腔が解剖学的に広がっている部位。
- **小脳延髄槽（大槽 / 後頭槽）**: 小脳と延髄背側の間にある最大の脳槽。大槽穿刺（後頭下穿刺）部位。
- **脚間槽**: 中脳大脳脚の間。
- **鞍上槽**: トルコ鞍の上方。
- **脳底槽**: 脚間槽・鞍上槽・交叉槽などの総称。**周囲に大脳動脈輪（ウィリス動脈輪）が形成される**。

### 2. 脈絡叢 (Choroid plexus)
- **存在部位**: **側脳室、第三脳室、第四脳室のすべての脳室**に存在する。
- **組織構造**: 脳室壁が薄くなり、**軟膜、毛細血管網、上衣細胞（上衣細胞が特化した脈絡叢上皮細胞）**が脳室内に突出して形成される。タイト結合により血液脳脊髄液関門を形成。

### 3. 脳脊髄液 (CSF) の機能と数値
- **総量**: 成人で約 **120〜150 mL**（脳室内に約20〜30mL、クモ膜下腔に約100〜120mL）。
- **1日の産生量**: 約 **450〜500 mL**（1日に約3〜4回入れ替わる）。
- **主な機能**:
  1. **物理的浮力**: 約1,400gある脳が髄液の浮力によって約 **50 g** の実効重量に軽減され、脳底部の血管・神経の自重圧迫を防ぐ。
  2. **衝撃吸収・緩衝作用**: 外部からの機械的衝撃を吸収・分散する。
  3. **化学的環境の恒常性・老廃物排出**: 脳実質の代謝産物を回収して静脈系へ排出する。

### 4. 脳脊髄液の循環ルート（完全順序）
【脳脊髄液の循環ルート】
側脳室（脈絡叢で産生）
  ↓（室間孔 / モンロー孔）
第三脳室（脈絡叢で産生）
  ↓（中脳水道 / シルビウス水道）
第四脳室（脈絡叢で産生）
  ↓（正中口 / マジャンディー孔 ＆ 外側口 / ルシュカ孔×2）
クモ膜下腔（脳表および脊髄周囲）
  ↓
クモ膜顆粒（パッキオーニ顆粒）
  ↓
上矢状静脈洞（静脈血流へ吸収・排泄）

## 第8章：髄液採取手技（穿刺）と検査所見

### 1. 腰椎穿刺（ルンバール / Lumbar puncture）
- **穿刺目的**: 髄液採取（髄膜炎・出血の診断）、髄圧測定、クモ膜下麻酔（脊椎麻酔）。
- **穿刺部位**: **第4〜第5腰椎間 (L4-L5)** または第3〜第4腰椎間 (L3-L4) の**クモ膜下腔**。
- **解剖学的指標**: **ヤコビ線 (Jacoby's line)**＝左右の腸骨稜の最高点を結ぶ線。**第4腰椎 (L4) 棘突起**（またはL4-L5棘突起間）の高さに一致する。
- **安全性の根拠**: 成人の**脊髄下端（脊髄円錐）は第1〜第2腰椎 (L1-L2) の高さで終了**し、それより下位の硬膜嚢内は**馬尾**（神経根の束）と**終糸**のみが存在するため、針を刺しても脊髄実質を損傷しない。

### 2. 大（後頭）槽穿刺 (Cisternal puncture)
- 後頭骨下縁から環椎（C1）の間を通って**小脳延髄槽（大槽）**に穿刺し、CSFを採取する手技。

### 3. キサントクロミー (Xanthochromia)
- **定義**: 髄液遠心分離後の上清が黄色〜褐色を帯びる現象。**クモ膜下出血**の診断的指標。
- **色の経過と生化学的変色順序**:
  ヘモグロビン（桃色 / ピンク） → ビリルビン（黄色） → メトヘモグロビン（褐色）
- 穿刺時の血管損傷（穿刺事故 / 外傷性穿刺）による人工的出血と、真の病的なクモ膜下出血を鑑別するために重要。
