## 【第1回】脳の基本数値・循環生理・脳の全体区分（Q001〜Q025）

#### Q001. 成人日本人における正常な脳の平均重量として最も適切なものはどれか。
1. 約 500〜700 g
2. 約 800〜1,000 g
3. 約 1,200〜1,400 g
4. 約 1,800〜2,000 g
- **正解: 3**
- **解説**: 成人日本人の脳の重さの平均は約1,200〜1,400g（成人体重の約2%）です。

#### Q002. ヒトの脳重量が全身の体重に占める割合はおよそ何％か。
1. 約 2%
2. 約 5%
3. 約 10%
4. 約 15%
- **正解: 1**
- **解説**: 脳の重量は体重約60〜70kgの成人において約2%に相当します。

#### Q003. 心拍出量（全血流量）のうち、安静時に脳へ供給される割合はおよそ何％か。
1. 約 5%
2. 約 15%
3. 約 25%
4. 約 40%
- **正解: 2**
- **解説**: 安静時の心拍出量（約5L/分）のうち、約15%（毎分約750mL）が脳へ流入します。

#### Q004. 全身の総酸素消費量のうち、脳が消費する割合はおよそ何％か。
1. 約 5%
2. 約 10%
3. 約 20%
4. 約 35%
- **正解: 3**
- **解説**: 脳は体重比わずか2%の臓器ですが、全身の酸素消費量の約20%を消費する極めて高代謝な臓器です。

#### Q005. 脳血流が完全に停止した場合、脳組織が不可逆的な障害を受けずに生きられる限界時間はどれくらいか。
1. わずか 30秒〜1分
2. わずか 3〜4分
3. 約 10〜15分
4. 約 30分
- **正解: 2**
- **解説**: 脳が酸素なしで生きられるのはわずか3〜4分です。心肺停止から救命処置開始が3分経過すると救命率は75%、5分経過すると25%に急減します。

#### Q006. 激しい運動時における脳血流量の動態について、正しい記述はどれか。
1. 心拍出量の増加に比例して脳血流量は5倍に増加する。
2. 脳血管が収縮するため、脳血流量は安静時より減少する。
3. 心拍出量は5倍になるが、脳への絶対血流量（毎分約750mL）は安静時と変わらない。
4. 骨格筋への血流配分を優先するため、脳への血流は完全に遮断される。
- **正解: 3**
- **解説**: 運動時、心拍出量は5L/分から25L/分へと5倍になりますが、心拍出量に占める脳血流の割合は15%から3%へと低下し、脳への絶対血流量（毎分約750mL）は安静時も運動時も変わりません（脳血流の自動調節能）。

#### Q007. 安静時と運動時における心拍出量に占める脳血流割合の組み合わせとして正しいものはどれか。
1. 安静時：約5% ／ 運動時：約15%
2. 安静時：約15% ／ 運動時：約3%
3. 安静時：約20% ／ 運動時：約20%
4. 安静時：約30% ／ 運動時：約50%
- **正解: 2**
- **解説**: スライド4枚目のデータより、安静時は心拍出量の約15%、運動時は約3%となります。

#### Q008. 中枢神経系 (CNS) に属する器官の正しい組み合わせはどれか。
1. 脳 と 脊髄
2. 脳神経 と 脊髄神経
3. 脳 と 脳神経
4. 自律神経 と 末梢神経
- **正解: 1**
- **解説**: 中枢神経系 (central nervous system, CNS) は「脳」と「脊髄」から構成されます。

#### Q009. 末梢神経系 (PNS) に属するものの正しい組み合わせはどれか。
1. 終脳 と 間脳
2. 脳幹 と 小脳
3. 脳神経 と 脊髄神経
4. 大脳皮質 と 大脳基底核
- **正解: 3**
- **解説**: 末梢神経系 (peripheral nervous system, PNS) は「脳神経（12対）」と「脊髄神経（31対）」から構成されます。

#### Q010. 脊髄が収められている骨性の管はどれか。
1. 頸動脈管
2. 脊柱管
3. 卵円孔
4. 破裂孔
- **正解: 2**
- **解説**: 脊髄は椎骨が連なって形成される「脊柱管」の内部に位置します。

#### Q011. 脳と脊髄の境界部に位置する頭蓋骨の大きな開口部はどれか。
1. 大後頭孔
2. 頸静脈孔
3. 棘孔
4. 正円孔
- **正解: 1**
- **解説**: 脳（延髄）と脊髄は、後頭骨にある「大後頭孔（大孔）」の高さで移行します。

#### Q012. 脳の発生的区分において、「大脳」を構成する2つの区分はどれか。
1. 終脳 と 中脳
2. 終脳 と 間脳
3. 間脳 と 脳幹
4. 中脳 と 橋
- **正解: 2**
- **解説**: 大脳は「終脳（大脳半球）」と「間脳」から構成されます。

#### Q013. 「脳幹」を構成する3つの部位の組み合わせとして正しいものはどれか。
1. 間脳・中脳・橋
2. 中脳・橋・延髄
3. 橋・延髄・小脳
4. 終脳・間脳・中脳
- **正解: 2**
- **解説**: 脳幹 (brainstem) は上から順に「中脳」「橋」「延髄」の3つから構成されます。

#### Q014. 間脳に含まれる主な構造の組み合わせはどれか。
1. 尾状核 と 被殻
2. 視床 と 視床下部
3. 中心前回 と 中心後回
4. 赤核 と 黒質
- **正解: 2**
- **解説**: 間脳は主に「視床」と「視床下部」から構成されます。

#### Q015. 最も高次な脳であり、思考や人間らしさに関わる部分はどれか。
1. 終脳
2. 延髄
3. 橋
4. 小脳
- **正解: 1**
- **解説**: 終脳（大脳新皮質）は最も高次な機能を担い、理性や思考、人間らしさに関わります。

#### Q016. 生命維持（呼吸・循環・嚥下など）に直接関わる自律神経中枢が集まる部位はどれか。
1. 終脳
2. 延髄
3. 小脳
4. 嗅球
- **正解: 2**
- **解説**: 延髄には呼吸中枢、心臓血管中枢、嚥下・嘔吐中枢など生命維持に直結する中枢が集まっています。

#### Q017. 運動制御や平衡感覚、運動学習の中心的な役割を担う脳はどれか。
1. 終脳
2. 間脳
3. 小脳
4. 中脳
- **正解: 3**
- **解説**: 小脳は運動の協調性、筋緊張の調節、スムーズな運動制御の中心です。

#### Q018. 神経組織における「灰白質」の本質的な構成要素はどれか。
1. 髄鞘を持つ軸索の集まり
2. 神経細胞体（核）の集まり
3. グリア細胞の突起のみの集まり
4. 脳脊髄液で満たされた間隙
- **正解: 2**
- **解説**: 灰白質は神経細胞体（核）が集まっている領域で、肉眼的に灰色を帯びて見えます。

#### Q019. 神経組織における「白質」の本質的な構成要素はどれか。
1. 神経細胞体の集まり
2. 樹状突起のみの集まり
3. 髄鞘（ミエリン鞘）を持つ神経線維（軸索）の集まり
4. 毛細血管の密なネットワーク
- **正解: 3**
- **解説**: 白質は髄鞘（脂質を多く含む）に覆われた有髄神経線維（軸索）の集まりであり、白く見えます。

#### Q020. 終脳における灰白質の分布部位として正しいものはどれか。
1. 大脳皮質 と 大脳基底核
2. 大脳髄質 と 内包
3. 脳梁 と 放線冠
4. 錐体路 と 視放線
- **正解: 1**
- **解説**: 終脳の灰白質は、表面を覆う「大脳皮質」と、深部に存在する「大脳基底核」です。大脳髄質は白質です。

#### Q021. 左右の大脳半球を正中面で互いに連結している最大の交連線維はどれか。
1. 内包
2. 脳梁
3. 視放線
4. 弓状束
- **正解: 2**
- **解説**: 左右の大脳半球は「脳梁」と呼ばれる巨大な横行線維束によって強固に連結されています。

#### Q022. 大脳表面に多数存在する「シワ（凹凸）」の意義として最も適切なものはどれか。
1. 脳脊髄液を貯留するための空間を増やすため
2. 限られた頭蓋腔内で大脳皮質の表面積（神経細胞数）を最大化するため
3. 脳の血流を減速させて脳圧を下げるため
4. 脳の重量を重くして安定性を保つため
- **正解: 2**
- **解説**: 脳の溝（シワ）があることで、容積を増やさずに大脳皮質の表面積を約3倍に広げることができます。

#### Q023. 間脳（視床・視床下部）の組織学的分類として正しいものはどれか。
1. 白質
2. 灰白質
3. 硬膜
4. 軟膜
- **正解: 2**
- **解説**: 視床や視床下部は多数の神経核（神経細胞体）が集まった灰白質です。

#### Q024. 大脳髄質の本質はどれか。
1. 大脳の白質（神経線維束の集まり）
2. 大脳の灰白質（神経細胞体の集まり）
3. 脳室を取り囲む上衣細胞層
4. クモ膜下腔の血管網
- **正解: 1**
- **解説**: 大脳髄質＝大脳の白質＝大脳の神経線維束です。皮質と深部核、または皮質同士を結ぶ情報の通り道です。

#### Q025. 大脳を左右の半球に二分する深い正中の切れ込み（裂）の名称はどれか。
1. 外側溝
2. 大脳横裂
3. 大脳縦裂
4. 中心溝
- **正解: 3**
- **解説**: 左右の大脳半球を正中で隔てる深い裂を「大脳縦裂」と呼びます（大脳鎌が入り込みます）。

## 【第2回】大脳外側面の解剖・脳溝と脳回（Q026〜Q050）

#### Q026. 前頭葉と頭頂葉の境界をなす主要な溝はどれか。
1. 外側溝（シルビウス溝）
2. 中心溝（ローランド溝）
3. 頭頂後頭溝
4. 鳥距溝
- **正解: 2**
- **解説**: 中心溝（ローランド溝）は、前頭葉（中心前回側）と頭頂葉（中心後回側）を境する溝です。

#### Q027. 中心溝（ローランド溝）の解剖学的特徴として正しいものはどれか。
1. 外側溝と直角に完全に交わっている。
2. 外側溝まで届かないものが多い。
3. 後頭葉の先端まで連続している。
4. 左右の大脳半球を正中で完全に分断している。
- **正解: 2**
- **解説**: スライド9枚目に明記されている通り、中心溝は「外側溝まで届かないものが多い」という重要な特徴があります。

#### Q028. 前頭葉・頭頂葉と側頭葉を明瞭に境する極めて深い溝はどれか。
1. 中心溝
2. 外側溝（シルビウス溝）
3. 頭頂間溝
4. 帯状溝
- **正解: 2**
- **解説**: 外側溝（シルビウス溝）は外側面に深く走り、側頭葉を前頭葉・頭頂葉から隔てています。

#### Q029. 中心溝の直前に位置する脳回の名称はどれか。
1. 中心後回
2. 中心前回
3. 上前頭回
4. 縁上回
- **正解: 2**
- **解説**: 中心溝の直前（前頭葉側）にあるのが「中心前回（一次運動野）」です。

#### Q030. 中心溝の直後に位置する脳回の名称はどれか。
1. 中心前回
2. 中心後回
3. 上側頭回
4. 角回
- **正解: 2**
- **解説**: 中心溝の直後（頭頂葉側）にあるのが「中心後回（一次体性感覚野）」です。

#### Q031. 前頭葉の外側面を上下に走る溝によって分けられる3つの脳回の組み合わせはどれか。
1. 中心前回・中心後回・帯状回
2. 上前頭回・中前頭回・下前頭回
3. 上側頭回・中側頭回・下側頭回
4. 縁上回・角回・海馬傍回
- **正解: 2**
- **解説**: 前頭葉外側面は上前頭溝と下前頭溝により、「上前頭回」「中前頭回」「下前頭回」の3つに区分されます。

#### Q032. 側頭葉の外側面を前後に走る溝によって分けられる3つの脳回の組み合わせはどれか。
1. 上前頭回・中前頭回・下前頭回
2. 上側頭回・中側頭回・下側頭回
3. 上頭頂小葉・下頭頂小葉・角回
4. 紡錘状回・海馬傍回・歯状回
- **正解: 2**
- **解説**: 側頭葉外側面は上側頭溝と下側頭溝により、「上側頭回」「中側頭回」「下側頭回」に区分されます。

#### Q033. 頭頂葉の外側面において、頭頂間溝によって上下に分けられる領域はどれか。
1. 上前頭回 と 下前頭回
2. 上頭頂小葉 と 下頭頂小葉
3. 縁上回 と 帯状回
4. 中心前回 と 中心後回
- **正解: 2**
- **解説**: 頭頂葉外側面は頭頂間溝によって「上頭頂小葉」と「下頭頂小葉」に二分されます。

#### Q034. 下頭頂小葉を構成する2つの代表的な脳回はどれか。
1. 上頭頂小葉 と 中心後回
2. 縁上回 と 角回
3. 三角部 と 弁蓋部
4. 帯状回 と 海馬傍回
- **正解: 2**
- **解説**: 下頭頂小葉は前部の「縁上回（40野）」と後部の「角回（39野）」から構成されます。

#### Q035. 外側溝の上行枝と前枝に挟まれた、下前頭回の一部をなす領域の名称はどれか。
1. 三角部
2. 扁桃体
3. 歯状回
4. 鉤
- **正解: 1**
- **解説**: 下前頭回は弁蓋部、三角部、眼窩部に分かれ、三角部周辺がブローカの運動性言語中枢となります。

#### Q036. 外側溝の後端が切れ込むように入り込む、下頭頂小葉の前部にある脳回はどれか。
1. 角回
2. 縁上回
3. 中心前回
4. 上側頭回
- **正解: 2**
- **解説**: 外側溝の後端部を取り囲むように位置するのが「縁上回（40野）」です。

#### Q037. 上側頭溝の後端を取り囲むように位置する、下頭頂小葉の後部にある脳回はどれか。
1. 縁上回
2. 角回
3. 中心後回
4. 中側頭回
- **正解: 2**
- **解説**: 上側頭溝の後端を取り囲むように位置するのが「角回（39野）」です。

#### Q038. 外側面から観察した際、頭頂葉・側頭葉と後頭葉の境界の目安となる切痕はどれか。
1. 坐骨小切痕
2. 後頭前切痕
3. 頚静脈切痕
4. 鎖骨切痕
- **正解: 2**
- **解説**: 大脳外側下面の後方約4cmにある切れ込みを「後頭前切痕」と呼び、後頭葉の前方境界の指標となります。

#### Q039. 外側溝の奥深く、前頭葉・頭頂葉・側頭葉の皮質を押し広げると現れる「第5の葉」とも呼ばれる皮質はどれか。
1. 島（島葉）
2. 扁桃体
3. 海馬
4. 視床
- **正解: 1**
- **解説**: 外側溝の深部には「島（島葉 / Insula）」と呼ばれる皮質が隠れています。

#### Q040. 島（島葉）を表面から覆い隠している前頭葉・頭頂葉・側頭葉の皮質部分を何と呼ぶか。
1. 弁蓋部 (operculum)
2. 三角部
3. 膨大部
4. 虫部
- **正解: 1**
- **解説**: 島を覆い隠している皮質領域を「弁蓋部」（前頭弁蓋、頭頂弁蓋、側頭弁蓋/島弁蓋）と呼びます。

#### Q041. 島（島葉）の臨床的・画像診断上の意義として正しいものはどれか。
1. 脳脊髄液を直接採取する部位である。
2. CTやMRI読影時の指標として重要であり、脳外科的アプローチの進入路としても利用される。

- **正解: 2**
- **解説**: スライド15枚目記載の通り、島はCT・MRI読影時の指標として極めて重要で、脳外科的アプローチの際にもここから入る場合が多くあります。

#### Q042. 島の皮質および弁蓋部に局在している感覚中枢はどれか。

3. 一次聴覚野

- **正解: 2**
- **解説**: 島の皮質および前頭弁蓋・頭頂弁蓋には「味覚野」が存在します。

#### Q043. 側頭葉上面（外側溝の内部深面）に位置し、一次聴覚野を含む横方向の脳回はどれか。

#### Q044. 前頭葉が主に司る高次機能の組み合わせとして正しいものはどれか。
1. 思考、理性、性格、運動

#### Q045. 頭頂葉が主に司る高次機能の組み合わせとして正しいものはどれか。

#### Q046. 後頭葉が主に司る機能はどれか。
