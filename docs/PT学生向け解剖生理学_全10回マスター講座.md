### Vol.01：大臀筋は上部と下部で作用が真逆！？（股関節・歩行分析）
* **対応画像**: `PT_Curriculum_01.png`
* **学生がつまずく疑問**: 「大臀筋って教科書には『股関節伸展・外旋』って書いてあるけど、それだけで歩行分析できる？」
* **解剖生理の核心**:
  1. **線維ごとの作用逆転**: 大臀筋の上部線維は股関節の「外転」に作用し、下部線維は「内転」に作用します（大腿骨頭の運動軸を挟むため）。
  2. **腸脛靭帯（ITB）との強固な連結**: 大臀筋の約80%の線維は大腿骨粗面ではなく「腸脛靭帯」に停止します。つまり、股関節だけでなく膝関節の外側安定性にも直接関与しています。
  3. **立脚初期（IC〜LR）の真の役割**: ここで大臀筋は「股関節をグッと伸ばす（短縮性）」のではなく、急激に屈曲しようとする床反力に対して「耐える（遠心性収縮）」ことで体幹の前傾を防いでいます。
* **臨床の一言**: 「大臀筋筋力低下＝トレンデレンブルグ徴候」と安易に結びつけず、上部・下部のどちらが不全なのか、骨盤の回旋がどう代償しているかを触診で確かめましょう！

### Vol.02：膝が伸び切るとロックする！スクリューホーム運動の秘密（膝関節）
* **対応画像**: `PT_Curriculum_02.png`
* **学生がつまずく疑問**: 「膝は単純な蝶番関節じゃないの？なんで伸び切るときにねじれるの？」
* **解剖生理の核心**:
  1. **幾何学的構造の非対称性**: 大腿骨の内側顆は外側顆よりも前後に約1.5cm長いです。そのため、伸展していくと外側が先に終わり、内側だけが転がり続けるため、自然と「脛骨外旋（オープンキネティック時）」が起こります。
  2. **靭帯の巻き付きによる剛性化**: この終末回旋によって前十字靭帯（ACL）や側副靭帯がピンと張り詰め、筋肉の力をほとんど使わずに膝がピタッと安定（ロック）します。
  3. **解錠役「膝窩筋」の存在**: 膝を曲げ始めるときは、まず膝窩筋が収縮して脛骨を「内旋」させてロックを解きます（アンロック機能）。
* **臨床の一言**: 変形性膝関節症（膝OA）の患者さんで「膝が伸び切らない（伸展制限）」場合、この回旋運動が消失しているケースが非常に多いです！

### Vol.03：ペタペタ歩きの原因！？ヒールロッカーと前脛骨筋（足関節・歩行）
* **対応画像**: `PT_Curriculum_03.png`
* **学生がつまずく疑問**: 「前脛骨筋って背屈する筋肉でしょ？歩くときはいつ働いてるの？」
* **解剖生理の核心**:
  1. **ヒールロッカー（第1ロッカー）**: 踵接地（IC）の瞬間、踵を支点にして足部が前方に回転します。このとき前脛骨筋が働いていないと、足の裏がバタンと床に叩きつけられます（Foot Slap）。
  2. **遠心性収縮の美学**: 前脛骨筋は足を上に持ち上げるのではなく、重力に逆らって「ブレーキをかけながらゆっくり伸ばされる（遠心性収縮）」ことで、着地の衝撃を劇的に吸収しています。
* **臨床の一言**: 脳卒中片麻痺や腓骨神経麻痺の患者さんで歩行を観察するときは、「足が上がるか」だけでなく「着地が滑らかに減速できているか」に注目してください！

### Vol.04：なぜ肩が挙がらない？腱板と三角筋の力学バランス（肩甲帯・上肢）
* **対応画像**: `PT_Curriculum_04.png`
* **学生がつまずく疑問**: 「三角筋を筋トレすれば肩は高く挙がるようになるの？」
* **解剖生理の核心**:
  1. **フォースカップル（協調的偶力）**: 三角筋は腕を「真上に引き上げる（上方に骨頭をズラす）」ベクトルを持っています。対してインナーマッスル（棘下筋・小円筋・肩甲下筋）は骨頭を「臼蓋に引き寄せて下方に引き下げる」ベクトルを持ちます。
  2. **求心位の破綻がインピンジメントを生む**: インナーがサボって三角筋だけが頑張ると、上腕骨頭が上に突き刺さり、肩峰下で棘上筋腱が挟み込まれて激痛が走ります。
* **臨床の一言**: 「痛くて腕が挙がらない」患者さんには、アウターの筋トレではなく、まず骨頭を求心位に留める棘下筋・肩甲下筋の低負荷トレーニングから始めましょう！

### Vol.05：腹筋運動しても意味ない！？インナーユニットの同調収縮（体幹）
* **対応画像**: `PT_Curriculum_05.png`
* **学生がつまずく疑問**: 「腰痛の患者さんにはクランチ（上体起こし）を指導すればいいの？」
* **解剖生理の核心**:
  1. **インナーユニットの4つの壁**: 天井（横隔膜）、床（骨盤底筋群）、前と横（腹横筋）、後ろ（多裂筋）。この4つが同時にキュッと収縮して初めて「腹腔内圧（IAP）」が高まります。
  2. **胸腰筋膜のコルセット効果**: 腹横筋が収縮すると、胸腰筋膜を外側に引っ張り、腰椎の椎間関節をがっちりと安定させます。腹直筋を鍛えてもこのコルセットは作れません。
* **臨床の一言**: 息を止めて力ませるのではなく、「深く吐きながら下腹部を薄く凹ませる（ドローイン／ブレーシング）」動作が腰椎安定化の第一歩です！

### Vol.06：骨盤前傾で偏平足になる！？下行性運動連鎖のドミノ倒し（運動連鎖）
* **対応画像**: `PT_Curriculum_06.png`
* **学生がつまずく疑問**: 「足のアーチが潰れている患者さん、足の指の筋トレだけで治る？」
* **解剖生理の核心**:
  1. **下行性の運動連鎖**: 骨盤が過前傾する ➔ 股関節が内旋する ➔ 大腿骨に対して脛骨が外旋し膝が外反（X脚）になる ➔ 距骨が内前方に滑り落ち、距骨下関節が過回内する（足の内側縦アーチが潰れる）。
  2. **ドミノ倒しの真実**: 足部だけを治療しても、骨盤・股関節のアライメントが崩れていれば、立った瞬間に体重で再び足が潰れます。
* **臨床の一言**: 痛い場所（局所）だけを見るセラピストを卒業し、「骨盤から足へ」「足から骨盤へ」の全身の運動連鎖を評価できる視点を身につけましょう！

### Vol.07：ストレッチで筋肉が緩む理由！腱紡錘とIb抑制（神経生理学）
* **対応画像**: `PT_Curriculum_07.png`
* **学生がつまずく疑問**: 「なんでストレッチは反動をつけちゃダメで、じっくり伸ばすの？」
* **解剖生理の核心**:
  1. **筋紡錘（Ia線維）の伸張反射**: 筋肉が急激に引き伸ばされると、筋紡錘が「ちぎれる！」と危険を察知し、脊髄反射でその筋肉をギュッと縮めさせます（伸張反射）。反動をつけると逆効果になる理由がこれです。
  2. **腱紡錘（Ib線維）の自原抑制**: 筋肉と腱の移行部にある腱紡錘（ゴルジ腱器官）は、持続的な高張力を感知すると、「これ以上引っ張ると腱が剥がれるから緩めろ！」と介在ニューロンを介して筋を弛緩させます。
* **臨床の一言**: スタティックストレッチは「20〜30秒以上、痛気持ちいい強さで息を吐きながら維持」することで、初めてIb抑制が発動して筋膜・筋線維が根本から緩みます！

### Vol.08：歩行と手の動きは経路が違う！錐体路 vs 網様体脊髄路（神経理学療法）
* **対応画像**: `PT_Curriculum_08.png`
* **学生がつまずく疑問**: 「脳出血の患者さん、手の指は全然動かないのに、なんで歩く練習はできるの？」
* **解剖生理の核心**:
  1. **外側系（皮質脊髄路＝錐体路）**: 大脳皮質からダイレクトに手足の遠位筋へ指令を送る「巧緻運動・細かい随意運動」のハイウェイ。
  2. **内側系（皮質網様体脊髄路・前庭脊髄路）**: 脳幹を経由して体幹や下肢の近位筋をコントロールする「抗重力姿勢・粗大な立ち直り・歩行リズム」の無意識のシステム。
* **臨床の一言**: 片麻痺の方の歩行再建では、錐体路の回復を待つだけでなく、網様体脊髄路による「先行性姿勢調節（APA）」を促すアプローチが超重要になります！

### Vol.09：息を吸うと肩がすくむ！？横隔膜と呼吸補助筋の力学（呼吸生理学）
* **対応画像**: `PT_Curriculum_09.png`
* **学生がつまずく疑問**: 「患者さんの肩こりや首の緊張が、いくら揉んでも取れないのはなぜ？」
* **解剖生理の核心**:
  1. **安静時換気の主役**: 通常の呼吸（1回換気量約500ml）の約70%は「横隔膜の上下動」と外肋間筋だけで行われます。
  2. **呼吸補助筋の過剰動員**: 姿勢不良（猫背や円背）で横隔膜が平押しされ動かなくなると、首や肩の「斜角筋・胸鎖乳突筋・僧帽筋上部」をフル稼働させて胸郭を無理やり引き上げます（努力呼吸の日常化）。
* **臨床の一言**: 1日に約2万回も肩をすくめて呼吸していれば、首や肩の筋肉が凝り固まるのは当然です。頸部のマッサージをする前に、肋骨の可動性と横隔膜のドーム機能を取り戻しましょう！

### Vol.10：ベッドから起こすのが怖い！？起立性低血圧と圧受容体反射（内部障害・離床）
* **対応画像**: `PT_Curriculum_10.png`
* **学生がつまずく疑問**: 「長期入院の患者さんを起こしたら、急に顔が真っ青になって倒れそうになった！何が起きた？」
* **解剖生理の核心**:
  1. **重力による静脈還流の激減**: 寝ている状態から急に立ち上がると、重力によって約500〜800mlの血液が一瞬で下肢や腹部にプールされます。
  2. **圧受容体反射の遅延**: 本来なら頸動脈洞や大動脈弓の圧受容器が「血圧低下」を即座に感知し、迷走神経を抑制＋交感神経を刺激して心拍数と末梢血管抵抗を跳ね上げます。しかし数日間のベッド上安静でこの反射機能が著しく低下します。
* **臨床の一言**: ギャッジアップ（30°➔60°）を段階的に行い、足関節の底背屈運動（ミルキングアクションによる筋ポンプ）を併用しながら、血圧・脈拍・自覚症状（眼前暗黒感）を必ず確認して離床を進めましょう！
