# Google Workspace ミニツール #002: スプレッドシートからGoogleカレンダーへ予定を一括登録

## 概要
スプレッドシートにまとめた予定（タイトル・日時・終日フラグ・場所・詳細）を、Googleカレンダーにワンクリックで一括同期するGASツールです。

## 主な機能
- **ワンクリック一括登録**: メニュー「🗓️ カレンダー一括登録」→「▶ 今すぐ予定を一括登録する」
- **二重登録防止**: 登録完了した行には「✅ 登録完了」が付き、次回以降は自動スキップ
- **事前件数チェック**: 「🔍 未登録の予定を件数確認する」で対象件数を確認可能
- **終日予定・通知時間設定**: チェックボックスによる終日指定、ダッシュボードでの通知分数変更に対応
- **安心停止・アンインストール機能**: 「🛑 ツールを停止・完全解除する」で設定を安全初期化

## 納品アセット
- `Code.js`: 本番GASコード
- `appsscript.json`: 最小スコープ定義
- `article.md`: note記事用原稿（黄金テンプレート準拠）
- `x_post.md`: X投稿用原稿
- `thumbnail.jpg`: 16:9 黄金サムネイル画像
- `videos/demo_sheets_to_calendar.gif`: X投稿用軽量ループGIF (263KB)
