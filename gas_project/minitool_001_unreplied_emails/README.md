# 未返信メール一覧ツール（ダッシュボード・トリガー機能付き）

「コピペで試せるGoogle Workspaceミニツール」第1弾  
Gmailの未返信候補（自分が最後に送ったまま、相手から返信が来ていないスレッド）を検出し、専用のGoogleスプレッドシートへ自動一覧化するツールです。

---

## 🌟 バージョン2.0の主な新機能

1. **⚙️ 管理・設定シート（ダッシュボード）の新設**:
   - スプレッドシート内の「設定・使い方」シートから、**探索日数（例: 7日、14日、30日など）を自由に指定**可能。
   - 最終実行日時や検出件数、自動更新トリガーの状態が一目で分かります。
2. **📮 スプレッドシート直結のカスタムメニュー**:
   - スプレッドシートの上部メニューに **「📮 未返信メールツール」** が追加され、シート上からワンクリックで実行可能。
3. **⏰ 毎朝の自動実行トリガー（タイマー）機能**:
   - メニューからワンクリックで「毎朝 8:00〜9:00」の自動更新トリガーを設定・解除可能。
4. **📸 記事用サンプルデータ生成機能**:
   - note記事のスクリーンショット撮影用に、架空のビジネスメール一覧を安全に出力可能。

---

## 📋 シート構成

- **`設定・使い方` シート**:
  - 探索日数の入力（C6セル：初期値14日）
  - 実行ステータス（最終更新日時、検出件数、トリガー有効状態）
  - 使い方ガイド
- **`未返信一覧` シート**:
  - 相手（名前＋メールアドレス）
  - 件名
  - 最終送信日
  - 返信待ち日数
  - Gmailで開くリンク（ワンクリックで該当スレッドへ直接ジャンプ）

---

## 🚀 使い方

### 1. 日数の変更
スプレッドシートの「設定・使い方」シートを開き、**C6セルの数値**を好きな日数（例: `30` や `7`）に変更します。

### 2. 今すぐ実行する
- **スプレッドシートから**: 上部メニュー「📮 未返信メールツール」→「▶ 今すぐ一覧を更新する」
- **GASエディタから**: 関数 `exportUnrepliedEmailsToSheet` を選んで「実行」

### 3. 毎朝自動で更新する
- 上部メニュー「📮 未返信メールツール」→「⏰ 毎朝の自動実行を設定する」をクリック。
- これで毎朝自動的にスプレッドシートが最新化されます！

### 4. 記事用の画面を撮る（ダミーデータ）
- 上部メニュー「📮 未返信メールツール」→「📸 記事用サンプルデータを出力」
- （またはGASエディタで `outputSampleDataForArticle` を実行）
- 個人情報を一切写さずに、綺麗な実画面キャプチャを撮影できます。
